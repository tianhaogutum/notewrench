# Fixture provenance

`old.txt`, `new.txt`, and `student.txt` are **real Anki 26.9.4 note-text exports**,
generated by [`make_examples.py`](make_examples.py) from invented course data.
The script uses the official headless Anki library's `Collection.export_note_csv`
with HTML, GUID, notetype, deck, and tags enabled. It creates no package files and
never reads a real profile. GUIDs differ between the teacher and student snapshots
to exercise the rule that student identity must win. This is deliberately harder
than copies of one original deck, whose GUIDs would normally match.

The teacher model has Front, Back, CourseID; the student's same-name model adds
Personal. Cases include a changed first field, an independent answer correction,
a concurrent answer edit, a teacher deletion, a student deletion, a teacher
addition, a student-only note, HTML/media references, Chinese text, and embedded
newlines. All educational content here is synthetic and MIT-licensed.

Regenerate with `python examples/anki-merge/make_examples.py` (needs the `anki`
package); GUIDs will change because Anki creates new notes each time. Tests also create genuine exports and
imports inside disposable collections. Additional parser tests construct focused
invalid inputs and format variants; they are labeled as synthetic in test code.

Use `--out examples/anki-merge/SUBDIRECTORY` with the generator to reproduce a
variant. The old exporter is verified for reading; its importer has a separately
reproduced repeated-import defect (see the [Anki versions](../../docs/anki-merge.md#tested-anki-versions)
section of the docs).
